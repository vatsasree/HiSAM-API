Endpoints

  • /polylines/process - Submit a job for processing.
  • /polylines/status - Check the status of a job.
  • /polylines/status/tei - Get the results in TEI-P5 format.

/polylines/process

You can submit one or more documents to be processed.
Supported file types are .jpg, .jpeg, .png, .pdf

Parameters

Field Type Description
files File(s) Image or PDF files (.jpg, .png, .pdf) 
curl -X POST "https://skeleton.iiit.ac.in/api/v1/polylines/process/" \
    -H "accept: application/json" \
    -H "X-API-Token: YOUR_TOKEN" \
    -F "files=@/path/to/image" \
    -F "files=@/path/to/pdf"

Expected Response

{
  "job_id": "job_uuid",
  "message": "Job accepted for processing.",
  "document_count": 2
}

Sample Python script to submit a job
Usage:
python submit_job.py --input-dir /path/to - To submit a job of documents from a directory.
python submit_job.py --files /path/to/file1.jpg /path/to/file2.pdf - To submit a job with a list of file paths.
python submit_job.py --url https://sample.com/pdf/file.pdf - To submit a job using a pdf url.

/polylines/status/{job_id}

You can check the status of a job with its job_id (uuid).
Parameters

Field Type Description
job_id UUID Job Id (in UUID format) 
curl -X GET "https://skeleton.iiit.ac.in/api/v1/polylines/status/JOB_ID" \
     -H "accept: application/json" \
     -H "X-API-Token: YOUR_TOKEN"

Expected Response

{
  "job_id": "job_uuid",
  "status": "PROCESSING",
  "documents": [
    {
      "doc_path": "image1.jpg",
      "status": "COMPLETED"
    }, 
    {
      "doc_path": "image2.jpg",
      "status": "PROCESSING"
    }
  ]
}

Sample Python script to check job status
Usage: python check_job_status.py --job-id JOB_ID

/polylines/status/tei/{job_id}

You can check get the results of the job using the job_id (uuid) as XML in TEI-P5 format.
Parameters

Field Type Description
job_id UUID Job Id (in UUID format) 
curl -X GET "https://skeleton.iiit.ac.in/api/v1/polylines/status/tei/JOB_ID" \
     -H "accept: application/json" \
     -H "X-API-Token: YOUR_TOKEN"

NOTE:
When a pdf file is submitted, the individual pages of the pdf file will be procssed and returned seperately in the XML.
If a document is named sample_docs.pdf and have 5 images, the outputs will be in the format sample_docs_page_0000.jpg, sample_docs_page_0001.jpg ... sample_docs_page_0004.jpg.
Refer '' tag in the sample XML format given below.

Sample TEI-P5 XML Format

<TEI xmlns="http://www.tei-c.org/ns/1.0">
<facsimile>
    <!-- Page 1 -->
    <surface xml:id="page1">
      <graphic url="page1.jpg" width="1000" height="1400"/>
      <zone xml:id="page1_line1" points="100,200 300,200 300,220 100,220" type="line"/>
      <zone xml:id="page1_line2" points="100,250 320,250 320,270 100,270" type="line"/>
    </surface>

    <!-- Page 2 -->
    <surface xml:id="page2">
      <graphic url="page2.jpg" width="1200" height="1600"/>
      <zone xml:id="page2_line1" points="120,300 500,300 500,320 120,320" type="line"/>
      <zone xml:id="page2_line2" points="130,350 480,350 480,370 130,370" type="line"/>
    </surface>
</facsimile>
</TEI>

<TEI xmlns="http://www.tei-c.org/ns/1.0">
  <facsimile>
    <!-- Page 1 -->
    <surface xml:id="page1" ulx="0" uly="0" lrx="1000" lry="1400">
      <graphic url="page1.jpg" width="1000" height="1400"/>

      <!-- Polygonal zone representing the text-line polygon -->
      <zone xml:id="page1_zone1" points="100,200 300,200 300,220 100,220" type="line"/>

      <!-- Path elements representing the text-line scribble -->
      <path xml:id="page1_path1" points="120,300 500,300 500,320 120,320"/>
      <path xml:id="page1_path2" points="130,350 480,350 480,370 130,370"/>

      <!-- Embedded binarized image -->
      <binaryObject mimeType="image/gif">
        R0lGODdhMAAwAPAAAAAAAP///ywAAAAAMAAwAAAC8IyPqcvt3wCcDkiLc7C0qwy
        GHhSWpjQu5yqm......
      </binaryObject>
    </surface>
  </facsimile>
</TEI>  

    surface: one page of the document
    graphic: page image metadata
    zone: one text-line polygon
    path: one scribble line
    points: list of coordinates (in pixels)
    binaryObject: binarized image as binary object.

Note: By default you will get access to only the predicted polygons. For other response objects like scribbles and binarized image, contact the admin.

Sample Python script to get the XML result

Extras

Python script to overlay the polygons using the TEI-P5 xml file
Overlay detected text-line polygons on original images.
Usage: python overlay_polygons_from_tei.py --docs_dir /path/to/documents --xml_path /path/to/tei.xml --output_dir /path/to/

Python script to overlay the scribbles using the TEI-P5 xml file
Overlay detected text-line scribbles on original images.
Usage: python overlay_scribbles_from_tei.py --docs_dir /path/to/documents --xml_path /path/to/tei.xml --output_dir /path/to/

Python script to crop the text-lines from images the TEI-P5 xml file
Crop the individual text-lines from the images.
Usage: python extract_textlines_from_tei.py --docs_dir /path/to/documents --xml_path /path/to/tei.xml --output_dir /path/to/

Python script to save the binary map using the TEI-P5 xml file
Save the binary map generated by the api.
Usage: python save_binary_images.py --xml_path /path/to/file.xml --output_dir /path/to/
